Welcome to my blog! This is my first post using Astro Content Collections.

## What is Astro?

Astro is a modern static site generator that allows you to build fast websites with your favorite UI frameworks. It ships zero JavaScript by default and supports multiple frameworks like React, Svelte, Vue, and more.

## Why Content Collections?

Content Collections provide type-safe markdown content with:

- Schema validation using Zod
- Automatic TypeScript types
- Built-in frontmatter parsing
- Easy querying and filtering
